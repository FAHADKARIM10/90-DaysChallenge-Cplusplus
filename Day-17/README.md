constructore 
A constructor is a special method that is automatically called when an object of a class is created 

constructor rules =>

The constructor has the same name as the class.
It has no return type (not even void).
It is usually declared public.
It is automatically called when an object is created.

The principle of combining data(attributes) and method functions into a single unit(class) 
and restricting direct access to some of the object components

It is a tyoe of constructor automataticlly created by the compiler if no constructor is defined 
.It takes no argument and initializes memebers with default values
